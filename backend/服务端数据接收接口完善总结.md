# 服务端数据接收接口总结

## 说明

本文档描述的是当前 `japan-aquaculture-project/backend` 中与数据接收相关的接口，不再使用旧名称 `japan_server`。  
接口校验、字段映射和实际行为应以 `routes/data_collection_routes.py`、相关服务模块及数据库模型为准。

## 当前主要数据接收接口

### 1. 传感器数据

- 接口：`POST /api/data/sensors`
- 内容类型：`application/json`

示例：

```json
{
  "sensor_id": 1,
  "batch_id": 2,
  "pool_id": "4",
  "value": 25.5,
  "metric": "do",
  "unit": "mg/L",
  "timestamp": 1234567890000,
  "type_name": "溶解氧传感器",
  "description": "4号池 - do"
}
```

### 2. 喂食机数据

- 接口：`POST /api/data/feeders`
- 内容类型：`application/json`

示例：

```json
{
  "feeder_id": "AI",
  "batch_id": 2,
  "pool_id": "4",
  "feed_amount_g": 68.0,
  "run_time_s": 120,
  "status": "ok",
  "leftover_estimate_g": 50.0,
  "notes": "定时投喂 4 份",
  "timestamp": 1234567890000
}
```

说明：

- `feeder_id` 可能是字符串，服务端会做兼容处理。

### 3. 操作日志

- 接口：`POST /api/data/operations`
- 内容类型：`application/json`

示例：

```json
{
  "operator_id": "user001",
  "batch_id": 2,
  "pool_id": "4",
  "action_type": "投料",
  "remarks": "正常投喂操作",
  "attachment_uri": "s3://bucket/file.pdf",
  "timestamp": 1234567890000
}
```

### 4. 摄像头图像

- 接口：`POST /api/data/cameras`
- 内容类型：`multipart/form-data`
- 文件字段：`file`

附带表单字段示例：

```text
camera_id=1
batch_id=2
pool_id=4
timestamp=1234567890000
width_px=1920
height_px=1080
format=jpg
```

## 相关实现位置

- 路由：`routes/data_collection_routes.py`
- 数据清洗：`services/data_cleaning_service.py`
- 模型：`db_models/`

## 当前文档口径

当前实现至少覆盖：

- JSON 数据接收
- 基本字段校验
- 时间标准化
- 校验和生成
- 异常值检测（部分数据类型）
- 数据库存储

## 测试示例

以下命令默认按当前 Backend 端口 `5002` 编写。

### 传感器数据

```bash
curl -X POST http://localhost:5002/api/data/sensors \
  -H "Content-Type: application/json" \
  -d '{
    "sensor_id": 1,
    "batch_id": 2,
    "pool_id": "4",
    "value": 25.5,
    "metric": "do",
    "unit": "mg/L"
  }'
```

### 喂食机数据

```bash
curl -X POST http://localhost:5002/api/data/feeders \
  -H "Content-Type: application/json" \
  -d '{
    "feeder_id": "AI",
    "batch_id": 2,
    "pool_id": "4",
    "feed_amount_g": 68.0,
    "run_time_s": 120,
    "status": "ok"
  }'
```

### 操作日志

```bash
curl -X POST http://localhost:5002/api/data/operations \
  -H "Content-Type: application/json" \
  -d '{
    "operator_id": "user001",
    "batch_id": 2,
    "pool_id": "4",
    "action_type": "投料"
  }'
```

### 摄像头图像

```bash
curl -X POST http://localhost:5002/api/data/cameras \
  -F "file=@/path/to/image.jpg" \
  -F "camera_id=1" \
  -F "batch_id=2" \
  -F "pool_id=4" \
  -F "format=jpg"
```

## 注意事项

1. 本文档是接口总结，不应替代代码核对。
2. 若生产环境改了端口、反向代理或上传目录，应以实际运行配置为准。
3. 与文件上传相关的接口在另一个蓝图中，路径是 `/api/v1/upload` 和 `/api/v1/upload/multiple`，不要和本文件中的 `/api/data/*` 混淆。
